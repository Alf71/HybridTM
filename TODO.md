Reuse or port from these rather than reimplementing TBX/GlossML parsing in HybridTM.
  - Not just a separate TBX/GlossML import path: when importing XLIFF 2.x (ts/xliffHandler.ts), any `<gls:glossary>`/`<gls:glossEntry>` elements already present on a `<unit>` should also be parsed out and stored as terms (using the same glossary-item flag), not just left embedded in the unit's stored content. This is a distinct source feeding the same term store as TBX/GlossML import.
